# Introduction

German Easy Language (\enquote{Leichte Sprache}) follows a well-defined set of rules to simplify standard German texts and aims to make information more accessible to people with text-comprehension difficulties. Although German Easy Language strives to be inclusive, it faces difficult challenges created by maximizing sentence simplicity, for example in gender-inclusive phrasing.
The generic masculine form (\enquote{generisches Maskulinum}) is widely used to express gender-neutral statements, but it is often replaced or supplemented by the gender-star convention \cite{Misersky2019Grammatical}, which makes sentences more complex again.
Although there is no standard for gender-neutral language in German Easy Language, this paper investigates whether there is a difference in gender bias between standard German and German Easy Language, and to what extent this bias is recognizable in images generated by a text-to-image model prompted with both Easy Language and standard German extracted from the previously investigated dual-text corpus.
