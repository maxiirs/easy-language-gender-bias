# adapted_from_paper

Dieser Ordner ist fuer spaetere Adaptionen aus dem im Paper referenzierten `corpus_pipeline` vorgesehen.

Zum Zeitpunkt der Einrichtung war der lokale Klon `corpus_pipeline` leer:

- Git-Repository vorhanden
- keine Commits
- keine Dateien im Worktree

Sobald der korrekte Projektinhalt vorliegt, koennen hier gezielt uebernommene oder angepasste Module abgelegt werden, zum Beispiel:

- Actor-Extraction
- Pronomen- oder Gender-Zuordnung
- Predication-/Nomination-Logik
- Coreference-nahe Komponenten
